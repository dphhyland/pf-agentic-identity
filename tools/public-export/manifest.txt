# The public tree's allow-list: what tools/export-public.py copies into ID-Partners/pf-agentic-identity.
# docs/development/public-export.md says what each class means and how to add a document.
#
# One rule per line:  <class> <source-glob> [-> <public-path>] [optional]
#   class        root, docs, image, demo (exported); internal (not exported, links into it are de-linked);
#                refuse (never exported: a rule of another class whose source matches one is an error)
#   source-glob  a path relative to the repository root; * matches within one directory, ** across them
#   public-path  where it lands; a path ending in / is a directory the glob's remainder is laid out under.
#                Without one, the file keeps its source path.
#   optional     the source may not exist yet (a file another pull request adds); without it, a rule that
#                matches nothing is an error on HEAD
# Rules are read in order and the first that matches a file wins, so an exclusion goes before its glob.
