Agentic identity for PingFederate

Servlets, SDK plugins, libraries and services that let an AI agent or workload get a token it can be held to.

OpenID Federation · Client Attestation · RFC 9396

Trust the type.
Prove the instance.
Decide at issuance.

An agent type is an OpenID Federation entity. Each running instance authenticates with a Client Attestation bound to its own key. At issuance, PingFederate can ask a policy decision point about the authority requested and, through a mapping not yet verified, read the instance's recorded device state.

      What the platform does not do

      Limits that matter before you rely on it.

      Servlets & web applications

      Servlets that run inside PingFederate's web container. pf-integration, attestation-issuer and ssf use @WebServlet annotations, and the image build registers the pf-integration and ssf filters in web.xml. gm-api.war declares its servlets in its own web.xml.

      SDK plugins

      Implementations of a PingFederate SDK interface, each shipping a PF-INF descriptor for PingFederate to discover. The registry plugin's descriptor name and mapping are unverified (docs/unverified.md item 9).

      Libraries & services

      The libraries import nothing from PingFederate. The services are a standalone enrolment process, a resource-server library and a command-line verification harness.
